# الهروب من نهاية العالم - تطبيق أندرويد

كل مرة كترفع تعديل على `main`، GitHub Actions كيبني APK أوتوماتيكيا.

## الطريقة
1. دير repository جديد ف GitHub.
2. رفع هاد الملفات كاملين (بما فيهم المجلد `.github`).
3. سير لـ **Actions** ← **Build APK** ← تسنى حتى يولي أخضر (حوالي 5 دقايق).
4. هبط **escape-end-of-world-apk** من الأسفل، حل الـ zip، وركّب الـ APK فالتيليفون.

باش تبدل اللعبة: بدل `www/index.html` ورفعو، والـ APK كيتبنى من جديد.
